# positivethots.org (marketing site)

Static pages served from the Namecheap Stellar hosting at `public_html/positivethots.org/`.
They are not part of the Lovable app build; this folder is the source copy.

- `index.html`, `privacy.html`, `terms.html`: images are embedded, so the files are large.
- Fonts load from `/fonts/` on the same host (copied from `public/fonts/`), so visitors never contact Google.

Nov 27, 2026: contact emails moved to @positivethots.org, a "Do Not Sell or Share My Personal
Information" link was added to every footer, and Google Fonts was replaced with the self-hosted copy.
Backups of the earlier versions are on the server as `*.bak-20261127.html`.
